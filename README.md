# 双栏校勘器

规范修订文本常有重复条款。普通按行对照在遇到同长路径上的删除时，可能把删除项判到不同位置，
校勘员无法凭原行号复核。本工具在浏览器内对旧版/新版双栏文本求 **Myers 最短编辑脚本（SES）**，
给出最少编辑次数、两侧原行号与连续变更块；对重复行保证稳定地删除靠后的旧版行。

- 前端：TypeScript + React 18 + Vite，纯静态产物，无后端、无外部请求。
- 比较规则：按行比较，**区分大小写、保留空白**（仅以 `\n` 分行，`\r` 属于行内容；`white-space: pre-wrap` 原样显示空格）。
- 替换不设独立操作类型，固定显示为**删除行后紧邻插入行**。

## Myers 实现要点（`src/diff/myers.ts`）

- `x`、`y` 为已消费行数，`k = x - y`，`d` 为编辑路径长度。
- `d = 0`：从 `(0,0)` 贪心匹配相同行。
- 此后每层按 `k` 以步长 2 递增搜索：
  - `k = -d` 边界选**插入**；`k = d` 边界选**删除**；
  - 中间仅当 `V[k-1] < V[k+1]` 时选插入，否则选删除（相等取删除——这是
    旧版 `"A\nA"` → 新版 `"A"` 稳定删除**旧版第 2 行**而非第 1 行的关键）；
  - 随后沿对角线贪心前进。
- 保存每一层 `V`，到达右下角 `(n,m)` 后从终点反向回溯，先退回对角线再取插入/删除，
  最终反转得到正序编辑脚本。

### 连续变更块（`src/diff/blocks.ts`）

相邻的插入/删除（即替换或连续编辑）合并为一个变更块，块内按「先删除、紧邻插入」渲染，
横幅给出旧版/新版原行号区间与删/增行数；相同行在块外双栏对齐显示。

### 限额与失效（`src/diff/validate.ts`、`src/App.tsx`）

- 每侧最多 **2000 行**；每行最多 **500 个 UTF-16 码元**（以 JS `string.length` 计；
  常见汉字为 1 个码元，emoji 通常为 2）。
- 按行号顺序报告**首个**违规：在前 2000 行内找首个超长行；若总行数超过 2000，
  首个违规恒为**第 2001 行**（行数超限），不会跳到第 2001 行之后才出现的超长行。
- 超限时**同时列出旧版与新版各自的首个违规行号**，并立即清空旧结果（结果区不渲染）；
  输入恢复合法后结果自动重新出现。

## 本地运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建到 dist/
npm test           # Vitest：Myers 搜索与回溯、变更块、限额
npx playwright test   # Playwright：重复行证据、零编辑、失效交互
```

## Docker

```bash
# 静态站点，宿主端口默认 8080，可用 WEB_PORT 覆盖：
WEB_PORT=9000 docker compose up --build web
#   打开 http://localhost:9000

# 一次性校验服务：Vitest + 生产构建 + Playwright，结束即退出：
docker compose build verify
docker compose run --rm verify
```

`Dockerfile` 为多阶段构建：

| target | 内容 |
| --- | --- |
| `build`（中间层） | 运行 Vitest 并构建静态产物 |
| `web` | nginx 托管 `dist/`（compose 默认服务） |
| `verify` | Playwright 官方镜像，依次跑单测、构建、端到端测试 |

## 验收锚点

- 相同输入：最少编辑次数为 **0**，无变更块。
- 旧版 `"A\nA"` 对新版 `"A"`：最少 **1** 次编辑，删除项为**旧版第 2 行**（E2E 默认场景即此例）。
